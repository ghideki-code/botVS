# Instruções para agentes

## Princípios de trabalho

- Preserve todas as funcionalidades existentes.
- Analise o código e a estrutura relevante antes de modificar qualquer arquivo.
- Faça alterações pequenas, organizadas e diretamente relacionadas à tarefa solicitada.
- Evite alterações não relacionadas à solicitação do usuário.
- Não apague arquivos, código ou funcionalidades sem autorização explícita do usuário.

## Git e branches

- Nunca modifique a branch `main`.
- Trabalhe somente na branch atual; não troque, crie, faça merge ou rebase de branches sem autorização explícita do usuário.

## Compatibilidade do projeto

- Não introduza frameworks, bibliotecas ou dependências novas sem autorização explícita do usuário.
- Mantenha HTML, CSS e JavaScript compatíveis com a estrutura atual do projeto.
- Antes de refatorar, confirme que a mudança é necessária para a tarefa e preserve o comportamento existente.

## Validação e comunicação

- Depois de cada alteração, execute os testes ou verificações que forem possíveis e proporcionais à mudança.
- Ao concluir, informe quais arquivos foram alterados e explique brevemente o motivo de cada alteração.
